# Prestige Service Jordan

Independent Arabic-first responsive cleaning service website. Business name, service categories, phone, and social accounts are based on the supplied Instagram screenshot. Site photos are illustrative stock imagery, not claimed customer projects. Original logo displayed from the supplied screenshot.

Static source is at the repository root. Serve with any static web server. The quote form opens WhatsApp with the visitor's selected service, region and notes; no submission is stored.

## Deployment

The GitHub Actions workflow publishes the root static files to GitHub Pages on pushes to `main`. In repository Settings → Pages, select GitHub Actions as the source. Arabic is served at `index.html`; English at `en.html`.
